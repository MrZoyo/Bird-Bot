# Bird-Bot Legacy Archive

[English](./README.md) | [简体中文](./README.zh-CN.md)

This branch preserves sanitized historical reference material removed from `main`: retired implementations, pre-refactor snapshots, legacy JSON examples, and old update notes.

Start with [`LEGACY_ARCHIVE_INDEX.md`](./LEGACY_ARCHIVE_INDEX.md) for the file inventory and restore examples.

## Safety Boundary

- The branch has one root commit and inherits no earlier Git history.
- Real configuration files, logs, local experiments, and runtime data are excluded.
- Discord invite links in archived material use placeholders.
- Files under `old_function/` are reference material, not supported runtime code.

To inspect the archive locally:

```bash
git fetch origin
git switch legacy-old-files-archive
```
