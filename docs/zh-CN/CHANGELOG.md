## 2.0.9 — 2026-09-23

- 恢复满员前原来的 Discord 频道链接。2.0.8 为保存名称而改用了带名称的 Markdown 链接，意外改变了未满员消息的外观。
- 房间名单独写入邀请记录；删除事件先保存最后名称，再编辑消息，重试和重启后仍可恢复。
- 自动新增可空的 `voice_channel_name` 列，迁移可重复执行，保留已有邀请状态和计数。升级前备份数据库；依赖、邀请排行榜样式和 30 小时助力福利保持不变。

## 2.0.8 — 2026-09-23

- 满员邀请保留语音房间名称：频道缓存缺失时查询 Discord，房间删除时使用事件携带的频道对象；新邀请保存可供后续恢复的名称。
- 无法找回名称的旧邀请显示频道 ID，明确不存在的频道标注已删除。缓存查询暂时失败仍可重试。
- 私人房间助力用户默认增加 30 小时语音时长，商店说明与购买、续费折扣使用相同默认值；显式配置仍优先，设置为 0 可关闭加成。
- 邀请排行榜保留原来的 `@用户` 显示。此次不追溯修改已结束的历史消息。
- 从 2.0.7 升级无需增加依赖或迁移数据库。已有部署需更新 `privateroom.yaml` 的 `booster_discount_hours: 30`，随代码部署新增邀请 locale 键，并保留服务器定制文案。

## 2.0.7 — 2026-09-17

- 用 `/ga_change <giveaway_id>` 替代 `/ga_description`。通过私密确认面板修改原活动的奖品、说明、提供者、中奖人数、总时长、参与门槛和图片。
- 门槛修改后，已报名者保留参与和中奖资格；新报名及主动退出后重新报名的用户按新门槛检查。总时长仍从原发布时间计算。
- 拒绝编辑已到期活动或覆盖其他管理员已保存的设置。编辑、结束、延期和面板刷新共用活动锁；消息更新失败时恢复设置，不覆盖参与记录。
- 上传图片按附件文件名引用，避免编辑、刷新和结束活动时重复显示图片。图片表单先应答，再下载上传文件。
- 新增 16 项回归用例，全量 215 项离线测试通过。从 2.0.6 升级无需增加依赖或迁移数据库；保留生产定制文案、备份数据库和密钥，在线完成候选验证后再短暂停机切换。

## 2.0.6 — 2026-09-13

- 组队邀请按钮支持重启后继续使用，取消原来的十分钟回调失效。“满员”结束当前这一轮邀请，房间仍可继续使用、再次组队。
- 邀请使用待发布、活跃、已结束状态；每个房间最多一条活跃邀请，展示板持续显示到满员、新邀请替换或房间删除。
- 两个满员入口统一按邀请 ID 结束记录。房间内非发布者通过面板结束邀请时，看板也会正确移除；旧点击不能结束新邀请。
- 新回复发送成功后再原子替换旧邀请，发送失败时保留上一轮。消息更新状态持久化并有限重试，发送结果不确定时不重复发送。
- 增加旧记录迁移和旧消息兼容提示。升级前备份加密数据库并演练迁移；升级后的邀请数据不能直接交给旧版到期清理器处理。
- 为首次应答失败增加时延诊断并停止后续操作。偶发 Discord `10062` 的具体原因仍未确认，本版不宣称消除网络或网关延迟。
- 通过 199 项离线测试、加密库迁移、真实 Discord 消息读回，以及用户在重启后、邀请存在约 16 分钟时的真实点击；普通消息替换和房间控制面板联合验证通过。
